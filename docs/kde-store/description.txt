SeaQ Snap Layout – snap layouts for KDE Plasma 6

Drag a window to the top edge of the screen: a bar with layouts slides down. Drop the window onto a zone and it fills exactly that area. Drag it away again and it gets its old size back.

A pure KWin script – no extra program, no background service.

MORE WAYS TO SNAP (each one can be switched on and off on its own)
• Screen edges: push a window against an edge or corner – top = maximize, left/right = halves, bottom = bottom half, corners = quarters
• Hold to fill: held a moment longer at an edge, the window grows up to the next window
• No double previews: KDE's own edge tiling and snap zones pause while the script runs
• Smart fill: if a window already sits at the bottom, the top edge fills only the space above it
• Window magnet: windows stick to each other and to the screen edges instead of sliding over, adjustable snap distance and resistance
• Sticky edges: resize a window and the windows touching it follow – no overlap, no gap; shake the mouse to let go
• Keyboard shortcuts: 20 actions, six key schemes (default Ctrl+Alt + key: arrows = halves, U I J K = quarters, D F G = thirds, E Y = two thirds, Return = maximize, C = center, - = restore) or your own keys; keys already in use are shown and can be taken over

FEATURES
• Six layouts in the bar, eleven templates in the designer
• Layout designer: split zones side by side or top and bottom, drag the dividers, up to 16 zones
• Drag & drop to reorder layouts, hide, duplicate or delete them
• Landing preview that shows where the window will end up
• System, light or dark snap bar, system accent, swatches or any color from the color wheel
• Bar size, thumbnail width, corner radius, opacity, several rows, layout and zone names
• Trigger distance, handle, delays, slide distance, slide-in/out durations, six motion curves (defaults based on Windows 11)
• Gaps between windows and to the screen edge, excluded applications
• Multi-monitor, Wayland and X11
• Settings editor uses your color scheme, window decoration and system language (62 languages)

OPENING THE SETTINGS
System Settings → Window Management → KWin Scripts → gear icon next to "SeaQ Snap Layout" → "Open Snap Layout settings editor" → OK.

GOOD TO KNOW
Plasma's own edge tiling and snap zones are paused automatically while SeaQ Snap Layout runs, so only one preview appears. Nothing is changed in your KDE settings – switch the script off or remove it and Plasma behaves as before.

After updating, log out and back in once – KWin keeps loaded scripts in memory.
